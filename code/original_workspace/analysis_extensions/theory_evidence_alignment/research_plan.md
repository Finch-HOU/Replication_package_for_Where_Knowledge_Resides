# Research plan

The benchmark is November 7 Table 3, verified against the full-population archives and copied before the extension. The study compares relative first-entry gradients across the existing Class C candidate universe. No-Specialist is the primary outcome. Total, Specialist and Signed are estimated on the identical denominator. An increase in Signed can reflect a more negative No-Specialist slope.

## Unified specifications

Run the original ten interactions plus directional applicability interacted with both gains and with month. Compare with Table 3, the archived joint applicability and specialist-access model, and a nonlinear model that adds squared gap, distance and applicability with both gains and month slopes. These alternatives distinguish availability, relatedness, access and location. Report all terms, partial-regressor variation, covariance-aware differences and path diagnostics. Purely linear reparameterizations count as the same result.

## Architecture matching

Reassign historical destination input profiles within the original OpenAlex fields and among destinations supported by the mapping. Use complete derangements where a field has enough alternatives. For singleton strata use other profiles in the same OpenAlex domain and disclose the fallback. Compare a field shuffle with predetermined matched assignments balancing historical profile shape and candidate distributions of gap, distance, shared coverage and applicability. Donor matching uses a seeded uniform core sample and frozen information only. Fix assignment rules, seeds and a finite run budget before viewing any placebo estimates. Record the quality of every draw. Similar donor profiles can retain true activity signal, which makes this a demanding specificity diagnostic.

Register eight draws per scheme and mapping. The matching objective equally weights median-normalized Hellinger distance between 2010–2014 input profiles and risk-weighted standardized RMS differences in gap, distance, shared coverage and applicability. Minimum-cost within-field derangements use seed-specific uniform cost jitter in [0, 0.25]. The seeded sample of 24,000 cores is split equally into matching and quality-audit halves. Match and estimate in numbered batches. If the complete-risk fit budget is binding, finish whole batches in index order and flag any remaining registered draws explicitly.

Keep actual eligibility, timing, events, HomeGain and DestinationGain. Construct donor gap, distance, shared coverage, applicability and distributed coverage by evaluating the same core histories against the donor activity. Use the original mapped risk-set means and SDs for both actual and donor quantities. In the head-to-head comparison retain both actual and donor conventional controls. Estimate actual U only, donor U only, and both U measures with their corresponding gain interactions and month slopes. Joint covariance and aligned capability-path influences support within-model and cross-model differences. A construct-placebo rank describes the chosen reassignment procedure. A tail fraction is not a causal randomization p-value.

Before inspecting any placebo fits, register an equal-weight mean of actual-minus-donor coefficients across all eight seeds within each scheme and mapping. Average aligned path influence vectors before forming the standard error. The four mean No-Specialist tests per mapping (two schemes and joint versus separate models) form their own Holm family. Their estimand is the contrast averaged over the fixed donor assignments. Seed counts provide no extra independent observations or capability shocks.

The initial support audit showed that a global within-field reassignment can pair a core with a donor field in which it already had experience. Before inspecting any placebo coefficients, add one core-specific stress test per mapping. Select among other frozen Class C destinations within the core, prioritizing the same field, then the same domain, then any eligible destination. Within each tier, minimize squared normalized profile distance plus the mean squared standardized gap, distance, shared coverage and applicability discrepancies, with small seeded jitter. This permits donor reuse and has no permutation reference distribution. If a core has only one eligible candidate, retain that candidate and flag the non-Class-C donor fallback. Use the same three fit types and include the contrast in the draw-level Holm family.

## Screening and verification

For economic magnitudes, use the holdout cores to find observed within-core candidate pairs in the same broad field and capability path. Require gaps, distance, shared coverage and applicability within 0.25 original-risk SD each. Choose the largest positive distributed-coverage contrast under that rule and use the third lowest and third highest observed HomeGain within the core. Report the eligible share and quantiles of the resulting exposure products. This illustrates the U contribution to the conditional gradient over observed covariate contrasts.

Prioritize full original risks, coherent controls, comparable scale, rank, common support, effect stability, aligned covariance, and the ten-path sensitivity. Keep complete coefficient and model records. Report raw two-sided capability-path probabilities and Holm correction across new primary No-Specialist focal/contrast tests within each mapping and investigation. Mappings share the same capability histories. Report tests on other outcomes descriptively. The work can support an observational association. The evidence for correctly matched architecture requires separation from defensible donor measures.

## Reproduction

From this directory with the workspace's scientific Python environment, run `python -B run.py freeze`, then `python -B run.py parent --stage all` and `python -B run.py direct --stage all`. Each mapping first verifies Table 3, then estimates the unified specifications and the four global placebo batches. Cached full-risk moments make a repeated solve inexpensive. For parallel batches, run `run.py <mapping> --prepare-placebos` first for each mapping, then `queue_runs.py 0 1 2 3`. Use `conditional_placebo.py <mapping>` for the Class C stress test and `support.py <mapping>` for observed magnitudes. Run `collect.py` to rebuild the result CSVs, contrasts, figures and registry. Run `audit.py <mapping>` to reconstruct the donor coverage inputs and `audit.py outcomes` for the final full-risk fit audit. The fitted arrays, path influence vectors and source manifest live under `fits/`, `cache/` and `frozen_table3/`.
